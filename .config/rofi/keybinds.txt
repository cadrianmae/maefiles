# Launchers
Alt+Space          App Launcher (rofi)
Mod+T              Terminal (kitty)
Mod+P              Clipboard History
Mod+Shift+Q        Power Menu
Super+Alt+L        Lock Screen

# Navigation (Vim)
Mod+H              Focus Left
Mod+J              Focus Down (cross workspace)
Mod+K              Focus Up (cross workspace)
Mod+L              Focus Right
Mod+Ctrl+H/J/K/L   Move Window

# Workspaces
Mod+1              Mocha
Mod+2              Strawberry
Mod+3              Kitty
Mod+U              Workspace Down
Mod+I              Workspace Up
Mod+O              Overview
Mod+Ctrl+1/2/3     Move to Workspace

# Windows
Mod+Q              Close Window
Mod+F              Maximize Column
Mod+Shift+F        Fullscreen
Mod+V              Toggle Floating
Mod+C              Center Column
Mod+W              Toggle Tabbed

# Sizing
Mod+R              Cycle Width (1/3, 1/2, 2/3)
Mod+Minus/Equal    Width -/+ 10%
Mod+Shift+-/=      Height -/+ 10%

# Columns
Mod+[              Consume/Expel Left
Mod+]              Consume/Expel Right
Mod+,              Consume into Column
Mod+.              Expel from Column

# Screenshots
Print              Screenshot
Ctrl+Print         Screenshot Screen
Alt+Print          Screenshot Window

# System
Mod+Shift+E        Quit Niri
Mod+Shift+P        Power Off Monitors
Mod+Shift+/        Show Hotkey Overlay
